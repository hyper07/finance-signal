# Final FRL submission checklist

## Author decisions

- [ ] Replace every bracketed field in `Title_Page.md` and `Cover_Letter.md`.
- [ ] Confirm the corresponding author, e-mail, full postal address, and ORCIDs.
- [ ] Obtain approval of author order and final text from all three authors.
- [ ] Complete each author's CRediT roles.
- [ ] Select and confirm the funding statement.
- [ ] Confirm that operating the audited service is the complete conflict disclosure.
- [ ] Confirm whether and where the preprint will be posted.

## Security, rights, and release

- [ ] Rotate every credential currently or previously stored in the local `.env`.
- [ ] Confirm no credential was committed in any public Git history.
- [ ] Review earlier Git and Zenodo versions for licensed headline text.
- [ ] Publish a rights-safe Zenodo version containing the narrow aggregate,
      robustness output, figure, code, environment file, and manifest.
- [ ] Add the final Zenodo DOI to the manuscript data statement and as a dataset
      reference; do not cite the current v1 until that review is complete.
- [ ] Create an immutable Git release/tag from the exact submitted code.
- [ ] Confirm that the repository URL is public and resolves without login.

## Manuscript checks

- [ ] Rebuild all statistics and the combined vector figure.
- [ ] Confirm body word count is below 2,500 and the PDF is at most 14 pages.
- [ ] Confirm all five highlights are at most 85 characters.
- [ ] Inspect every PDF page at 100% and check Figure 1 at single-column size.
- [ ] Remove all bracketed instructions and draft notes.
- [ ] Confirm every author reviewed the AI-use declaration.
- [ ] Confirm references, URLs, event date, and 2026 news-source details.
- [ ] Run the repository tests and publication checks.

## Editorial Manager

- [ ] Create or update accounts for all authors.
- [ ] Enter the title, abstract, five keywords, and three JEL codes exactly.
- [ ] Upload `paper.pdf` as the manuscript.
- [ ] Upload the completed title page if requested separately.
- [ ] Upload `Highlights.txt` as Highlights.
- [ ] Upload `Cover_Letter.md` after converting it to PDF or Word if required.
- [ ] Upload `fig_frl_combined.pdf` separately if the system requests artwork.
- [ ] Add the Zenodo dataset DOI and repository URL as research data.
- [ ] Select subscription publication unless the authors intentionally choose
      optional open access.
- [ ] Pay the non-refundable USD 200 submission fee.
- [ ] Download and inspect the system-generated proof before approving submission.
